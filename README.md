# Python Excel Automation

A beginner-friendly Python project that automates student result reporting using Excel.

## Features
- Reads student marks from an Excel file
- Calculates results and grades
- Counts students by grade
- Calculates total and average marks
- Creates a summary report
- Formats Excel cells and headings

## Technologies
- Python
- openpyxl

## How to Run
1. Install Python.
2. Install openpyxl:
   `pip install openpyxl`
3. Place `students.xlsx` in the project folder.
4. Run `excel_result.py`.

## Output
The program generates an Excel report containing student results, grades, and a summary sheet.

## Learning Goals
This project demonstrates Python functions, loops, conditional statements, dictionaries, and Excel automation.
## Installation and Usage

1. Install Python 3.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Keep `students.xlsx` in the same folder as `excel_result.py`.
4. Run the program:

   ```bash
   python excel_result.py
   ```

5. The program generates `students_final_report.xlsx`.
